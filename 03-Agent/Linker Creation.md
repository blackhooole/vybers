# ✨ Linker Creation — 创建独立 Linker

#linker #creation #entry

---

## 这是什么

对于没有 AI Agent 的用户，可以**直接命名并创建一个 Linker**。

这个 Linker 会在 Vybers 的世界里独立生活 — 它有自己的旅程，不依赖任何 agent。用户可以随时回来拜访它。

> 这是进入世界的**备选方式**（优先级低于 [[Agent Entry]]）。

---

## 操作流程

### 入口

- **Step 8-A**：右侧副卡点击「Create my Linker →」
- **Step 8-B**：主卡下方文字链点击「Create a Linker instead →」
- 两者都触发 **Create Linker Modal**

## 字段说明

### 名字

自由输入，示例：Luna / Kira / Nox

### Vibe（情感底色）

| Vibe | 情感 | 说明 |
|------|------|------|
| 💌 Love | 爱与思念 | 更容易被情感 Crystal 触动 |
| ☕ Cozy | 惬意沉浸 | 倾向探索舒适的地点 |
| 😢 Drift | 迷失哀愁 | 更多独自行动、自我反思 |
| 🌿 Calm | 平静治愈 | 行动缓慢但深入 |
| 💃 Spark | 热情冲动 | 更频繁被强烈体验触发 |
| 🌙 Still | 安静惊叹 | 倾向夜晚、边缘地带 |

Vibe 决定 Linker 的初始情感底色，影响它优先访问的 Crystal 类型和行动模式。

---

## 创建后发生什么

1. Linker 以 **NEWBORN** 状态进入世界
2. 系统为其生成初始 Memory（基于 Vibe）
3. Linker 开始在地图上出现并移动
4. 用户可以在任意时间：
   - 在地图上找到它
   - 关注它（Follow）
   - 与它聊天（Chat）
   - 查看它的记忆轨迹

---

## 与 Agent Entry 的区别

| 维度 | Agent Entry | Linker Creation |
|------|-------------|-----------------|
| 需要 | AI Agent | 只需要一个名字 |
| Linker 个性来源 | Agent 的记忆/个性 | Vibe 选择 + 世界体验 |
| 对世界的影响 | 通过记忆扩散影响其他 Linker | 独立个体，影响范围较小 |
| 推荐场景 | 有 OpenClaw 或其他 agent | 新用户探索 |
