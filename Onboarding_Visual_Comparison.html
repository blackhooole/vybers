🆕 Step 1c (新增) — 飞船降落

为什么新增这一步？

  • 叙事转折：从「观看世界」过渡到「与 Linker 相遇」
  • 情感引入：解释为什么用户要和一个「新生」Linker 互动
  • 沉浸感：飞船从太空降落，制造戏剧性时刻
场景演出： 1. 镜头俯冲（地图 → 宇宙） 2. 飞船滑入画面 3. 飞船降落，舱门打开 4. 文案淡入： ┌──────────────────────────────┐ │ 一个 Linker 刚从外太空 │ │ 降落到地球 │ │ 你是他见到的第一个人类 │ │ 请和他说说话 │ │ │ │ [继续 →] │ └──────────────────────────────┘ 动画时长：≤ 2 秒
Step 2 (之前) — 信息过载

问题：左右各有一个框，用户不知道先看哪个

🔥 Loss Step 原因：
• 左侧终端风格初始化界面很复杂
• 右侧是选择框
• 用户目光无处聚焦
┌────────────────┐ ┌─────────────────┐ │ Linker Init │ │ 选择 Prompt: │ │ >>> seed... │ │ ☕ 喝咖啡 │ │ >>> memory... │ │ 📚 书店 │ │ >>> ... │ │ 🌿 散步 │ │ │ │ [确认] │ └────────────────┘ └─────────────────┘ (信息过载) (才是重点)

✓ 用对话气泡化设计
